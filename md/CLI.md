# CLI 指令说明（`cx`）

> 本文档用于统一说明 `cx` 命令行工具相关功能。部分能力当前可能尚未完全实现，作为后续工程实现与对齐的目标说明。

## 1. 包管理

### `cx init <pkgname>`
创建包骨架，用于初始化一个可发布/可安装的包目录结构。

### `cx install <path-or-name>`
安装包。

- 本地包示例：`cx install ./pkg`
- 未来可扩展：支持从远端源安装（待实现）

### `cx list`
列出当前已安装的包。

---

## 2. 工具链

### `cx`
打开命令菜单（入口命令）。

### `cx repl`
进入 REPL 交互环境。

### `cx run <file.cx>`
使用 VM 运行脚本或源码文件。

### `cx build <file.cx>`
进行原生编译（面向发布或性能场景）。

### `cx test`
运行测试框架。

### `cx fmt <file.cx>`
格式化代码。

### `cx gui`
启动 GUI 编辑器（含语法高亮）。
