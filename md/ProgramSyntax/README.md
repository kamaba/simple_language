# S Language Program Syntax

This directory contains human-readable syntax documentation for the S language.

Files:
- `introduction.md` - language overview
- `base.md` - base syntax and conventions
- `function.md` - functions and methods
- `class.md` - classes and inheritance
- `data.md` - data / record types
- `enum.md` - enums
- `interface.md` - interfaces
- `array.md` - arrays
- `forwhiledowhile.md` - loop constructs
- `if.md` - conditional statements
- `operator.md` - operators and precedence
- `type.md` - types and generics
- `variable.md` - variable declarations and scope

Use these files as a reference when authoring S code or writing examples.
