# 字符串

本篇说明如何在 S 语言里书写字符串、插值与拼接，供日常写代码查阅。

---

## 双引号 `"..."`（常用）

用一对英文双引号包住内容。

- **不能**在引号中间直接换行；需要换行时请写转义符（例如 `\n`）。
- 支持常见转义，例如：`\"`、`\\`、`\'`、`\/`、`{`、`}`、`\n`、`\t`、`\uXXXX` 等。

### 插值（在双引号字符串里）

在双引号字符串中，可以用 **`$`** 把变量或表达式嵌进字符串里：

| 写法 | 含义 |
|------|------|
| `$变量名` | 插入该变量的值；也支持用 `.` 连接的成员访问，例如 `$obj.field`。 |
| `${ 表达式 }` | 插入任意表达式的值；花括号可以嵌套，以匹配最外层的 `}` 为止。 |

**重要**：单独一个 **`{`** 在双引号里只是普通字符，**不会**像某些语言里的 `{0}` 那样表示占位符。  
若要把 **表达式** 插进去，必须用 **`${ ... }`** 包起来。

```text
// 正确：变量与表达式
"你好，$name"
"合计：${a + b}"

// 错误理解：下面里的 {a+b} 不会被当成表达式，只是字面量字符
"合计：{a+b}"      // 若需要计算，请写成 "合计：${a+b}"
```

插值片段在语言里会按从左到右的顺序参与运算，效果上等同于把各段用 **`+`** 拼成一个大字符串（非字符串会先变成文本再拼）。

## 单引号 `'...'`

用一对英文单引号包住内容。

- 只有 **`\'`** 用来表示单引号本身；其它字符大多按原样收录。
- **没有**双引号里的那种 **`$` / `${}` 插值**：`'$x'` 里的 `$x` 就是三个普通字符。

适合写「原样保留 `$`、`{`」的文本，或简单字面量。

---

## 多行字符串 `f""" ... """`

以 **`f"""`** 开头、以 **`"""`** 结束，中间可以跨多行书写。

- 适合做长文本、模板片段。
- 插值请使用 **`${ 表达式 }`**。
- **`f"""` 块里不要依赖「只写 `$变量名`」这种简写**：应写成 **`${变量名}`** 或保证与当前编译器约定一致；若简写未按插值处理，会得到字面量 `$` 与后续字符。

结束定界符必须是同一行的三个 `"` 连续出现（与开头对称），具体以你使用的编译器版本为准。

---

## 普通拼接：加号 `+`

任意两个值可以用 **`+`** 连接；只要有一侧（或两侧经转换后）是字符串，就会按 **文本拼接** 处理，另一侧通常会先变成字符串再拼。

```text
"前缀：" + x.toString()
```

---

## 占位符格式串（若使用标准库）

若语言/标准库提供了类似 **「格式串 + 参数表」** 的 API（例如按索引填坑），一般约定如下，**与双引号里的 `$` 插值不是同一套规则**：

- **`{0}`、`{1}`**：按数字取第几个参数。
- **`{}`**：按顺序自动使用第 0 个、第 1 个……参数。

具体函数名、参数类型以你所用的 **库文档** 为准；不要和 **`"${expr}"`** 混用同一套语法。

---

## 常见误区（速查）

1. **想在字符串里算表达式**：用 **`${expr}`**，不要只写 `{expr}`。  
2. **想原样保留 `$`**：用单引号字符串，或对 **`$` 转义**（双引号下按你环境中的转义规则）。  
3. **多行与单行**：单行双引号不能随意断行；长文用 **`f"""`** 或拆成多个字符串再用 **`+`**。
