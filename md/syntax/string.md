# 字符串

本文按 `LexerParse.cs` 当前实现整理（不是理想语法，而是“现在实际行为”）。

---

## 1) 支持的字符串字面量

### 1.1 双引号字符串 `"..."`

```sl
c2 = "a";
c6 = "aaaaaa";
```

支持转义：`\'`、`\"`、`\\`、`\$`、`\a`、`\b`、`\f`、`\n`、`\r`、`\t`、`\v`、`\0`、`\/`、`\{`、`\}`、`\uXXXX`。

### 1.2 单引号字符串 `'...'`

```sl
c1 = 'a';
string c3 = 'a';
```

当前实现里单引号也作为字符串处理。单引号字符串只对 `\'` 做特殊处理，其它 `\x` 基本按原样保留。

### 1.3 三引号字符串 `f"""..."""`

`LexerParse` 只识别这种前缀形式，不识别 `f"..."`。

---

## 2) 拼接

```sl
a2 = "aaacc" + "deee";
a3 = '{"name":"okr", "age":13, "info":{ "map":[1,2,3], "seq":"\n\n" } }' + 3;
c4 = 'a' + 'b';
```

---

## 3) `format` 示例

```sl
a41 = "{0} this is {1} that a {2}".format("mum", "skirt", "big");
#a42 = "{} this a {} ".format("qq", "girl")
```

说明：`{0}`、`{}` 是否替换由后续语义/运行时处理；词法阶段只把它们当字符串内容。

---

## 4) 双引号字符串里的 `$` 行为

```sl
a6 = "print a=$a4 ";
a7 = "print c1.a1=$c1.a1 ";
#a5 = "${ a+b+(3+10+\"aadf\").toString() }";
```

### 当前实现结论

- `$变量`、`$对象.成员`：已支持。
- `${表达式}`：已支持，适合函数调用、运算等复杂表达式。
- 普通 `{...}`（不带 `$`）只是字面文本，不是插值。

注意：`$v.toString()` 这种“带函数调用”的写法不属于 `$变量/$对象.成员`，应写成 `${v.toString()}`。

---

## 5) `f"""..."""` 的 `$` 行为

在 `ReadFTripleString()` 中：

- 支持 `${表达式}`。
- 不支持 `$变量` 简写（会按普通文本处理）。
