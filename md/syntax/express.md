# 表达式（Expressions）

表达式是计算并返回值的语法单元。S 语言中的表达式可用于：变量初始化、函数参数、返回语句、控制流条件、以及类级别或实例级别的赋值等位置。

1. 在类的静态成员（类变量）初始化时，可以使用表达式，但不允许使用需要实例上下文的非静态成员。
2. 表达式的类型推断：若表达式包含不同类型（例如 `object + int`），编译器将根据运算语义决定结果类型；若没有明确类型则退化为 `object` 类型。
3. 在普通语句上下文中，可以使用任意合法表达式，包括调用、算术运算、逻辑表达式等。

示例：

```s
class A {
    static Int32 sv = 1 + 2;
    Int32 iv = 3 * (1 + 2);
}

var x = foo(1 + 2, bar());
if (x > 10) {
    ret x;
}
```

算术与逻辑运算符遵循常见优先级；表达式会在 `ExpressManager` 中构建为 `MetaExpressNode`，并经过类型检查与简单优化（常量折叠）。
