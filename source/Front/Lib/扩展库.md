自定义语言标准库完整分层规划
参考 Dart/Go/C#/Java/Swift/Kotlin 所有成熟语言设计，把标准库拆为必带核心库（强制内置，隐式导入）、通用刚需库（默认自带，按需导入）、平台适配库（分系统可选导入）、配套工具库四层。所有模块遵循：最小依赖、可裁剪、跨平台统一接口、底层对接 OS。适配你之前关注的：引用计数内存管理、自定义 try/catch 异常、溢出检查、跨端兼容。
一、强制隐式导入：runtime 核心内置库（不用手动 import，全局可用）
对应 Java java.lang、Dart dart:core、Go builtin，所有程序 100% 必须，不可裁剪。
1. core 基础内核库
基础原始类型全集：有符号 / 无符号整数（8/16/32/64）、浮点数 f32/f64、布尔、字符串、字符、空类型、可选空安全类型；所有字面量、基础运算符归属此库。
顶层基础函数：打印输出、类型判断、类型转换、最值、取绝对值、类型反射基础。
容器基础：动态数组、有序哈希 Map、无序 Set、可迭代 Iterable 顶层协议。所有循环、遍历接口统一。
异常错误体系：适配你自定义的 try/catch/errdefer；内置通用 Error 基类、错误包装、异常堆栈捕获、恐慌 panic。
内存配套：适配你的引用计数 RC，内置内存申请释放、弱引用、裸指针（unsafe 裸内存）；内存越界基础检查。
时间基础：时间戳、毫秒 / 纳秒时长基础类型（DateTime/Duration），只存绝对时间，时区交给外层库。
并发最小原语：全局休眠、线程基础挂起唤醒；异步顶层 Future/Promise 基础接口。
常量：最大最小值、正负无穷、NaN、π、自然常数。
2. builtin 编译器内置函数库（无源码，编译器硬实现）
不用导入，语法层面直接调用：
长度获取、切片截取、容器扩容、堆分配、栈分配、类型强制转型、溢出开关（checked/unchecked）开关、GC/RC 手动触发。
二、通用刚需标准库（全平台统一 API，所有环境预装，按需 import）
Windows/macOS/Linux/ 移动端通用，接口完全一致，底层由运行时适配不同操作系统。开发文件、网络、加解密、序列化、并发必用。
1. str 字符串完整工具库
大小写、分割、拼接、替换、修剪、正则完整实现；
字符串与各类数字互转、进制转换；
Unicode 处理、UTF8/UTF16 字符分段、码点遍历。
2. bytes 字节操作库
对应 Go bytes、Dart typed_data
字节数组、固定大小缓冲区、读写游标；
二进制拼接、切片、查找、填充；
适配网络、文件、音视频二进制读写。
3. math 高级数学库
三角函数、指数对数、开方、取模、四舍五入；
随机数（安全随机 + 普通伪随机两套）；
高精度大数 BigInt/BigDecimal，解决浮点精度丢失；
位运算批量工具、进制换算。
4. encoding 序列化 & 编码全家桶
必带主流格式，统一编解码接口：
JSON（最刚需）、Base64、Hex 十六进制、UTF8/ASCII/GBK 字符编码；
可选内置：XML、Protobuf 极简版；
所有序列化支持自定义类型序列化钩子，适配你的自定义结构体。
5. time 完整时间日期库
补齐 core 的时间短板，跨时区无差异：
时区、日历、年月日时分秒格式化；
时间加减、时间差计算、日期区间；
定时器、延迟触发、周期定时。
6. fs 文件系统库
全平台一致路径 API，屏蔽 Windows 反斜杠、Unix 斜杠差异：
文件：创建、删除、读写、追加、权限、文件大小、修改时间；
目录：遍历、递归创建 / 删除、软链接；
路径工具：拼接、相对路径转绝对路径、后缀判断；
流式大文件读写，小文件一次性读写封装。
7. net 网络库（TCP/UDP/HTTP 三合一）
对标 Go net、C# System.Net.Http，一套 API 跨端：
底层：TCP 客户端 / 服务端、UDP、域名 DNS 解析；
高层：HTTP/1.1 完整客户端（GET/POST/Header/Body/ 超时）；
支持超时、连接复用、请求取消（对接你自定义 context 上下文）；
HTTPS/TLS 证书封装内置。
8. sync 并发同步库
适配多线程、多协程，配套你的异步体系：
互斥锁 Mutex、读写锁 RWMutex、一次性执行 Once；
等待组 WaitGroup、信号量、条件变量；
无锁原子操作 atomic：整数 CAS、原子增减。
9. context 上下文控制库
通用全链路控制，贯穿网络、文件、定时、协程：
统一能力：超时过期、主动取消、携带自定义参数；所有 IO、异步函数都支持挂载 context，一键终止整条调用链。
10. regex 正则表达式库
独立库，支持捕获分组、贪婪 / 非贪婪、多行模式；全局匹配、替换、查找。
11. crypto 加密哈希库
分普通哈希、对称加密、非对称加密，无第三方依赖：
哈希：MD5、SHA1、SHA256、SHA512；
对称：AES、DES；
非对称极简 RSA；
HMAC 加盐哈希。
12. collection 增强容器库
补充 core 基础容器的缺失结构：
队列 Queue、双端队列 Deque、有序 TreeMap、有序 Set、链表、不可变只读容器、环形缓冲。
三、分平台隔离标准库（同包名，不同系统实现，条件导入）
参考 Dart dart:io /dart:html 设计，一套代码通过编译宏区分平台，API 尽量对齐，不污染其他端。
1. os 操作系统适配库（桌面 / 服务端可用，浏览器禁用）
进程管理：启动子进程、杀掉进程、获取进程 PID；
环境变量、主机名、操作系统版本、CPU 架构；
控制台终端颜色、终端大小、键盘实时输入。
2. web 浏览器专属库（仅 Web 编译目标可用）
对接浏览器 DOM、Fetch、WebSocket、LocalStorage；
替代 net/fs，浏览器不能访问本地文件，全部走 web 接口；
和桌面端 net 包接口命名尽量相似，降低跨端改造成本。
3. mobile 移动端补充库（安卓 /iOS）
移动端特有：APP 沙盒路径、剪贴板、基础屏幕信息；不包含 UI（UI 属于框架，不属于标准库）。
四、高级配套标准库（可选预装，大型项目刚需，小型程序可裁剪）
不用强制预装，做成可选打包，小体积程序可剔除减小二进制：
archive：zip/tar/gz 压缩解压；
cli：命令行工具专用，参数解析、命令提示符、进度条；
testing：单元测试标准库，断言、测试用例、基准测速 benchmark；
log：分级日志库（debug/info/warn/error），支持文件落盘、控制台输出；
rpc：极简 RPC 基础封装（可选）；
math/geometry：矢量、矩阵、坐标，游戏、图形开发专用。
五、结合你的语言特性定制专属 stdlib 优化（重点适配你的设计）
你之前规划：自定义 try/catch、errdefer、RC 引用计数、checked 溢出、隔离多线程，标准库必须深度适配：
所有 IO、网络、文件函数统一用errdefer / 自定义异常双方案，既能手动接收错误码，也支持 try 捕获，兼顾 Go 式极简与 Java 式异常；
所有数值运算默认开启 checked 溢出，math、字节库可全局切换 unchecked 模式；
容器、字符串、二进制全部适配 RC 自动内存管理，裸指针单独隔离在 unsafe 子包，防止野指针滥用；
并发层同时支持：协程轻量级异步 + 操作系统线程，sync 库同时兼容两种调度模型；
全部标准库无全局隐藏状态，依赖 context 传参做超时、取消，方便并发安全。
六、最简最低配置版（嵌入式 / 微型编译目标裁剪方案）
如果你的语言要支持单片机、极小嵌入式设备，只保留这些，其余全部砍掉：
隐式：core + builtin；
必备：str、bytes、math、encoding (base64+utf8)、sync 原子锁、time 基础时间戳；
删除网络、文件、加密、正则、高级容器，最大限度瘦身。
七、最终推荐必装清单（通用全场景折中方案，95% 开发够用）
必装（不能删）
core、builtin、str、bytes、math、encoding、time、fs、net、sync、context、regex、crypto、collection
建议预装（推荐默认打包）
os、log、testing、archive
按需选配（根据编译目标开关）
web、mobile、cli、geometry
嵌入式专用：只保留 core、builtin、str、bytes、math、极简 encoding、atomic
